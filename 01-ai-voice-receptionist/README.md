## Overview
Built a 24/7 AI voice receptionist that handles inbound calls, answers business-specific questions, collects customer information, schedules appointments, and triggers automated follow-up through GoHighLevel.

## What it does
1. Answers inbound calls
2. Answers questions about services
3. Collects customer information
4. Schedules appointments
5. Adds the appointment to the calendar
6. Triggers an automated workflow

## Workflow
→ Customer calls
→ AI Receptionist
→ Customer Information
→ Appointment Booking
→ Calendar
→ Automated Workflow

## Technology

- AI Voice Agent
- GoHighLevel
- CRM
- Calendar
- Workflow Automation

# Why this is needed/ What problem it can solve
Businesses can miss potential customers when calls come in after hours or when staff are unavailable. I wanted to build a system that could handle these calls automatically while still connecting the customer to the business's existing scheduling and CRM workflow.
